# Reglas de Vibe Coding para IA

Este proyecto es un catálogo interactivo de herramientas (Dashboard, Bingo, Expositor) alojado en Firebase.

## 1. Arquitectura de Múltiples Subproyectos
- Todo el código se organiza en `src/apps/[nombre-del-proyecto]`.
- NUNCA mezcles la lógica de un subproyecto con otro.
- Utiliza `src/shared/` **solo** para componentes, configuraciones o utilidades que se usen en **dos o más** subproyectos (ej. `firebase.js`).

## 2. Documentación Local Obligatoria
- Cada subproyecto en `src/apps/` debe tener su propio `README.md` actualizado donde se detallen las variables, flujos, y responsabilidades específicas.
- Lee SIEMPRE el `README.md` del subproyecto antes de modificar su código.

## 3. Estilo y Estética (Vibe)
- Priorizar experiencias "WOW" utilizando colores vibrantes, glassmorphism, micro-animaciones y tipografías modernas.
- Usa CSS estándar localizado o global (como en `index.css`) con variables de diseño claras (ej. `--accent-blue`, `--glass-border`).

## 4. Gestión de Estado y Ruteo
- La navegación principal está controlada por `react-router-dom` en `App.jsx`. 
- No rompas el ruteo. Las herramientas individuales no deben intentar reescribir el estado global (`session`) sin interactuar mediante sus propios endpoints de Firebase o `localStorage` encapsulado.
